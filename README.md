### 🧭 About Me

I didn't start out in tech — my background is in **History Honours**, and I'm currently pursuing an **MCA**. Somewhere along the way, I realized that the same skills that made me good at history — reading patterns, building narratives from scattered facts, questioning sources — are exactly what data analysis needs too. Numbers tell stories the same way historical records do; you just need the right tools to read them.

So now, I'm learning to work with data the way I once worked with archives — carefully, curiously, and one dataset at a time. My goal is to become a **Data Analyst**, turning raw numbers into insights that actually help people make decisions.
